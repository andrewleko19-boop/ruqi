إضافة مادة

لمواد النشاط (التربية الرياضية، الموسيقية، الفنون الجميلة): يظهر للمعلّم زر يملأ علامات كل الطلاب بالحد الأقصى، ويبقى بإمكانه تعديل أي طالب قبل الحفظ.

مثل: مذاكرة، شفهي / وظائف، امتحان فصلي. مجموع الدرجات = العلامة العظمى للمادة.
