### وليُّ الأمر — رقم `0955123456`، والرمزُ كيف يُقرأ؟

**الحقيقةُ أوّلاً: لا يمكن قراءةُ الرمز من جدول `parent_otps`.** العمود اسمه
`code_hash` ويخزّن **بصمةَ SHA‑256 لا الرمز**، وهذا تصميمٌ أمنيٌّ مقصود — من
يقرأ الجدول لا يستطيع انتحالَ وليّ أمر.

**الطريقة الأولى (الموصى بها في التصوير):** الرمزُ يُطبَع في سجلّ الدالّة:

```
Supabase → Edge Functions → parent-auth → Logs
```
وابحث عن سطرٍ كهذا بعد ضغطك «إرسال الرمز»:
```
[parent-auth] OTP for +963955123456: 481902
```

**الطريقة الثانية (إن تعذّر بلوغُ السجلّ):** بعد طلب الرمز من التطبيق، شغّل
هذا في SQL Editor ليصير الرمزُ `123456` ثم أدخله:

```sql
-- بصمةُ SHA-256 للرمز 123456 محسوبةٌ مسبقاً.
update public.parent_otps
   set code_hash  = '8d969eef6ecad3c29a3a629280e686cf0c3f5d5a86aff3ca12020c923adc6c92',
       attempts   = 0,
       used_at    = null,
       expires_at = now() + interval '30 minutes'
 where phone = '+963955123456'
 order by created_at desc
 limit 1;
```

> لاحظ الصيغة: التطبيق يخزّن الرقم `+963955123456` (يحوّل `09…` إلى `+9639…`)،
> بينما تدخل أنت `0955123456` في شاشة الدخول. كلاهما صحيح.

### بعد التصوير
شغّل `tools/demo-reset.sql` — يمحو العرضَ كلَّه ولا يقارب بياناتك الحقيقية.

## ٤) الأدوات على ويندوز — بالترتيب

### ١. تسجيل الشاشة — **OBS Studio** (مجّاني، مفتوح المصدر)
obsproject.com · الإعدادات المهمّة:
- `Settings → Video`: Base و Output كلاهما **1920×1080**، FPS **60**
- `Settings → Output → Recording`: الصيغة **mp4**، Encoder **x264**، جودة
  «Indistinguishable Quality»
- أضِف مصدر **Display Capture** أو **Window Capture** (الثاني أنظف: لا يلتقط
  إشعارات ويندوز)
- **لا تسجّل الصوت مع الصورة** — سجّل الصورة صامتةً وأضِف الصوتَ في المونتاج.
  فإن أخطأتَ في جملةٍ لا تُعيد التصوير.

### ٢. المونتاج — **Shotcut** (أبسط) أو **DaVinci Resolve** (أقوى)
shotcut.org · resolve مجّانيٌّ أيضاً لكنّه ثقيل. للفيديو بهذا الحجم Shotcut يكفي.

### ٣. التعليق الصوتيّ بلا صوتك
| الخيار | كيف |
|---|---|
| **Edge Read Aloud** (مجّاني تماماً) | افتح Edge → الصق النصّ في ملفّ نصّيّ → `Ctrl+Shift+U` → اختر صوتاً عربياً (Hamed / Zariyah) → سجّل الناتج بـOBS كصوتٍ داخليّ |
| **ElevenLabs** | جودةٌ أعلى بكثير، ودعمٌ عربيٌّ ممتاز. الخطّةُ المجّانية تكفي لخمس دقائق |
| **Microsoft Azure TTS** | أصواتٌ عربيةٌ سورية/فصحى، مجّانيٌّ حتى حدٍّ شهريّ |

> نصيحة: العاميّةُ السورية لا تُنطق جيّداً في أغلب محرّكات TTS. إمّا أن تسجّل
> بصوتك (الأفضل بكثير للإقناع)، أو تحوّل السيناريو إلى فصحى مبسّطة قبل التوليد.

### ٤. ربطُ الشرائح بتسجيل التطبيق
1. افتح صفحة الشرائح في المتصفّح بملء الشاشة (F11) وسجّلها بـOBS: قِف على كلّ
   شريحةٍ ٣–٥ ثوانٍ.
2. سجّل كلَّ بوّابةٍ في **مقطعٍ منفصل** — أسهل في المونتاج من مقطعٍ واحدٍ طويل.
3. في Shotcut، رتّب المسار الزمنيّ هكذا:

```
المسار ١ (فيديو):  [غلاف][بوّابات] [المدرسة] [المعلّم] [المديرية] [الوزارة] [وليّ الأمر] [خاتمة]
المسار ٢ (صوت):    ───────────── التعليق الصوتيّ المتّصل ─────────────
المسار ٣ (موسيقى): ──── خلفيةٌ هادئة بمستوى ‎-25dB ────
```

4. بين كلّ مقطعين ضع انتقال **Dissolve** بطول **٠٫٥ ثانية** — لا أكثر.
5. التصدير: `Export → YouTube` أو H.264 بمعدّل بت **8–12 Mbps**.

> **قاعدةُ التزامن:** ركّب الصوتَ أوّلاً، ثمّ قُصَّ الفيديو ليلحق به — لا
> العكس. فالكلامُ هو ما يقود الإيقاع.
